# my-first-project

Мой первый проект — учусь делать сайты с помощью Claude Code.

## Что здесь есть

- **index.html** — лендинг-визитка (Anton Saprykin, коммерческий директор) с формой заявки.
- **about-me.html** — простая страница «Обо мне»: фото-заглушка, короткий текст и кнопка со ссылкой на почту.
- **about-me.txt** — три предложения о себе.

## Как посмотреть

Открыть файл `index.html` (или `about-me.html`) двойным кликом в браузере. Форма заявки на лендинге работает только когда запущен `node server.js`.
